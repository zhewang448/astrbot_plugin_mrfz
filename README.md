# 明日方舟角色语音插件 astrbot_plugin_mrfz

## v3.6.0

这是一个支持明日方舟所有角色、所有皮肤、全语言语音的 AstrBot 插件。
内置了 PRTS 终端风格的图片渲染引擎，支持模糊匹配和自定义语音绑定。

## ✨ 功能特点

- **全语音支持**：涵盖 中文(普通话/方言)、日语、英语、韩语、意大利语。
- **智能模糊匹配**：输错角色名也能自动识别（如 `/mrfz 阿米亚` -> 自动识别为 `阿米娅`）。
- **精美可视化**：生成 PRTS 终端风格的帮助菜单和干员列表。
- **自定义绑定**：可以将任意语音绑定到简短的触发词（如 `早安` -> `阿米娅 问候`）。
- **自动资源管理**：自动下载语音、自动爬取干员头像。
- **安全缓存**：校验并隔离损坏语音，列表与帮助图片固定覆盖缓存文件。

## 🛠️ 指令说明

| 指令                                       | 别名           | 功能说明                                                                                                                                               |
| :----------------------------------------- | :------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/mrfz [角色] [语音] [语言]`               | `播放明日方舟语音`、`播放方舟语音` | **核心指令**。角色支持模糊匹配；语音和语言均可省略。多皮肤角色可使用 `角色皮肤[皮肤名]` 精确指定。<br>📝 _示例：`/mrfz W皮肤[恍惚] 问候 中文`_ |
| `/mrfz_list`                               | `明日方舟语音列表` | 生成当前已下载语音的干员列表卡片，包含头像、已下载语言和自定义指令概览。 |
| `/mrfz_fetch [角色]`                       | `下载语音`、`获取语音` | **管理员指令**。从 PRTS Wiki 下载指定干员的所有语音数据（含皮肤）。 |
| `/mrfz_bind [触发词] [角色] [语音] [语言]` | `绑定语音`、`语音绑定` | **管理员指令**。将一句语音绑定到特定触发词。 |
| `/mrfz_unbind [触发词]`                    | `解绑语音`、`语音解绑` | **管理员指令**。解除指定的快捷触发词绑定。 |
| `/mrfz_help`                               | `明日方舟语音帮助` | 生成可视化的帮助图片。 |

## ⚙️ 配置项

配置文件位于 AstrBot 控制面板：

| 配置项                   | 类型   | 默认值     | 说明                                                                      |
| :----------------------- | :----- | :--------- | :------------------------------------------------------------------------ |
| `auto_download`          | bool   | `true`     | 未找到角色语音时，是否尝试自动下载。                                      |
| `allow_public_auto_download` | bool | `true` | 是否允许普通用户通过 `/mrfz` 触发自动下载；关闭后仅管理员可触发。 |
| `auto_download_skin`     | bool   | `true`     | 下载时是否包含皮肤语音。                                                  |
| `default_language_rank`  | string | `"123456"` | 播放时的语言优先级。<br>1:方言, 2:中文, 3:日语, 4:英语, 5:韩语, 6:意语    |
| `auto_download_language` | string | `"123"`    | 执行下载指令时，默认下载哪些语言（代码同上）。                            |

## 📂 目录结构

### 1. 插件安装目录

位于 `AstrBot/data/plugins/astrbot_plugin_mrfz/`：

```text
astrbot_plugin_mrfz/
├── main.py                 # 核心入口
├── data_source.py          # 数据源与下载逻辑
├── renderer.py             # 图片渲染模块
├── SourceHanSerifCN...otf  # 字体文件
├── _conf_schema.json       # WebUI 配置定义
└── requirements.txt        # 依赖列表
```

2. 插件数据目录
   位于`AstrBot/data/plugin_data/astrbot_plugin_mrfz/`：

```
astrbot_plugin_mrfz/
├── assets/                 # [自动生成] 干员头像缓存目录
│   ├── 阿米娅.png
│   └── ...
├── voices/                 # [自动生成] 语音文件存储目录
│   └── 阿米娅/
│       ├── cn/             # 中文语音
│       ├── jp/             # 日语语音
│       └── skin/           # 皮肤语音目录
├── custom_commands.json    # [自动生成] 自定义绑定数据
├── voice_index.json        # [自动生成] 本地语音索引缓存
├── render_cache/           # [自动生成] 固定的 help.png 与 list.png
└── quarantine/             # [自动生成] 隔离的损坏语音文件
```

## 📅 更新日志

### v3.6.0

- 全面升级多皮肤索引，列表直接显示 `W皮肤 · 恍惚` 等真实皮肤名称。
- 支持 `/mrfz W皮肤[恍惚] 问候 中文` 精确播放；多套皮肤未指定名称时会列出选项，不再自动选择第一套。
- 自定义绑定会固定到具体皮肤，避免后续新增皮肤后指向发生变化。
- 语音索引升级至 v4，记录稳定皮肤资源 ID、展示名称、实际目录、各语言 PRTS voice key 和资源编号映射版本。
- 修正语音资源的非连续编号映射；旧版错位缓存会在首次播放、绑定或手动下载时按角色和语言重新下载，确认 404 的旧文件会移入隔离目录。
- 首次启动会迁移旧版皮肤目录；只校验旧目录实际存在的语言和条目，不要求每套皮肤具备六种语言或固定数量的语音。
- 皮肤语音包缺少个别条目时，播放可回退到同语言的角色基础语音；迁移删除校验仍要求具名皮肤文件完整覆盖旧目录。
- 网络或写入失败时会保留旧目录和重映射标记，并于下次启动重试。
- 重做固定尺寸的明日方舟语音帮助终端页面。

## ⚠️ 注意事项

1. **资源来源**：所有语音和图片资源实时爬取自 [PRTS Wiki](https://prts.wiki/)，请遵守相关使用协议。
2. **网络问题**：批量下载语音时请确保网络通畅，以免下载不完整。
3. **文件删除**：可自行在`\data\plugin_data\astrbot_plugin_mrfz\voices\`目录下删除不需要的语音文件，并在之后重载插件。
