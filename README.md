# 明日方舟角色语音插件 astrbot_plugin_mrfz

## v3.8.2

这是一个通过 PRTS Wiki 获取明日方舟干员基础与皮肤语音的 AstrBot 插件，支持中文（普通话/方言）、日语、英语、韩语、意大利语、俄语、德语、西班牙语和法语；实际可用语音以 PRTS 登记的资源为准。
内置了 PRTS 终端风格的图片渲染引擎，支持模糊匹配和自定义语音绑定。

## ✨ 功能特点

- **多语言语音**：涵盖中文（普通话/方言）、日语、英语、韩语、意大利语、俄语、德语、西班牙语、法语，按上游资源清单下载。
- **智能模糊匹配**：输错角色名也能自动识别（如 `/mrfz 阿米亚` -> 自动识别为 `阿米娅`）。
- **干员别称识别**：内置“水陈、叔叔、红蒂”等常用别称，也支持管理员自定义别称。
- **精美可视化**：生成 PRTS 终端风格的帮助菜单和干员列表。
- **自定义绑定**：可以将任意语音绑定到简短的触发词（如 `早安` -> `阿米娅 问候`）。
- **自动资源管理**：通过 PRTS Wiki API 自动下载语音与干员头像；名称写错时给出相近干员名，PRTS 收录的别称会自动识别。
- **安全缓存**：校验 WAV 结构并隔离损坏语音；覆盖前备份，失败保留恢复材料；列表与帮助图片固定覆盖缓存文件。
- **Pages 管理端**：在 AstrBot WebUI 中试听、导入、导出、检查、回收和恢复语音文件。

## 🖥️ 语音档案控制台

AstrBot `>= 4.26.0` 会自动发现插件的 `voice-manager` Page。安装并重载插件后，
从 WebUI 的插件详情页打开“语音档案控制台”即可使用：

- 按干员合并展示基础与皮肤语音包，附头像；逐条查看 38 类语音状态，试听时显示台词。
- 在线试听、单条下载、整包导出、WAV 替换和 ZIP 批量导入。
- PRTS 干员列表：输入联想、列出尚未下载的干员并批量下载，后台任务显示实时进度。
- 索引重扫和 WAV 完整性检查。
- 快捷绑定管理、可恢复回收站、替换备份和操作审计。
- 皮肤档案中的基础回退语音只允许试听或导出，不会被误删。
- 提供新版与经典版两套界面，通过配置项 `page_style` 切换。

## 🛠️ 指令说明

| 指令                                       | 别名           | 功能说明                                                                                                                                               |
| :----------------------------------------- | :------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/mrfz [角色/皮肤] [语音] [语言]`          | `播放明日方舟语音`、`播放方舟语音` | **核心指令**。角色支持模糊匹配；语音和语言均可省略。可直接输入皮肤名称，或使用 `角色皮肤[皮肤名]` 精确指定。<br>📝 _示例：`/mrfz 超新星 问候 中文`、`/mrfz W皮肤[恍惚] 问候 中文`_ |
| `/mrfz_list`                               | `明日方舟语音列表` | 生成当前已下载语音的干员列表卡片，包含头像、已下载语言和自定义指令概览。 |
| `/mrfz_fetch [角色]`                       | `下载语音`、`获取语音` | **管理员指令**。从 PRTS Wiki 下载指定干员的所有语音数据（含皮肤）。 |
| `/mrfz_bind [触发词] [角色] [语音] [语言]` | `绑定语音`、`语音绑定` | **管理员指令**。将一句语音绑定到特定触发词。 |
| `/mrfz_unbind [触发词]`                    | `解绑语音`、`语音解绑` | **管理员指令**。解除指定的快捷触发词绑定。 |
| `/mrfz_alias [别称] [干员]`                | `添加干员别称`、`干员别称` | **管理员指令**。添加并保存自定义干员别称，例如 `/mrfz_alias 水陈 假日威龙陈`。 |
| `/mrfz_alias_list`                         | `干员别称列表` | 查看内置及自定义干员别称。 |
| `/mrfz_help`                               | `明日方舟语音帮助` | 生成可视化的帮助图片。 |

## ⚙️ 配置项

配置文件位于 AstrBot 控制面板：

| 配置项                   | 类型   | 默认值     | 说明                                                                      |
| :----------------------- | :----- | :--------- | :------------------------------------------------------------------------ |
| `auto_download`          | bool   | `true`     | 未找到角色语音时，是否尝试自动下载。                                      |
| `allow_public_auto_download` | bool | `true` | 是否允许普通用户通过 `/mrfz` 触发自动下载；关闭后仅管理员可触发。 |
| `auto_download_skin`     | bool   | `true`     | 下载时是否包含皮肤语音。                                                  |
| `default_language_rank`  | list | 方言、中文、日语、英语、韩语、意语 | 播放语言优先级，按列表顺序选择已有语音；未命中时仍回退到该干员已有语言。 |
| `auto_download_language` | list | 方言、中文、日语 | 自动下载的语言，多选；留空则不下载语音。管理员 `/mrfz_fetch` 获取该干员全部已支持语言。 |
| `page_style`             | string | `"modern"` | 语音档案控制台的界面：`modern` 新版，`classic` 经典版。保存后刷新页面生效。 |

直接选择中文语言名称，无需填写数字。支持方言、中文、日语、英语、韩语、意语、俄语、德语、西班牙语和法语。默认播放顺序和自动下载范围保持不变。

语音档案控制台新增“设置”页，两套界面均可修改全部配置；播放优先级可添加、移除和上下调整。保存后写入 AstrBot 的原插件配置并立即生效，新下载任务使用新设置，已创建任务保持原参数；界面样式在重新打开管理页面后切换。AstrBot 插件详情中的配置表单也可编辑同一份配置，由框架保存并重载插件。

更新后首次加载会自动把旧数字配置（如 `123456`、`10,2,3`）转换为语言名称列表，保留原顺序、下载范围和开关。旧配置先备份到插件数据目录的 `config_backups/`，再调用 `AstrBotConfig.save_config()` 保存；备份或保存失败时保留原配置，下次加载重试。底层键名保持兼容，以避免框架在加载插件前删除旧配置值。

播放时可直接指定语言，例如 `/mrfz 早露 交谈1 俄语`、`/mrfz 黑键 交谈1 德语`、`/mrfz 棘刺 交谈1 西班牙语`、`/mrfz 傀影 交谈1 法语`。语言使用固定支持列表，后续新增语言需更新映射；PRTS 未登记的音频或台词不会补造。

## 📂 目录结构

### 1. 插件安装目录

位于 `AstrBot/data/plugins/astrbot_plugin_mrfz/`：

```text
astrbot_plugin_mrfz/
├── main.py                 # 核心入口
├── data_source.py          # 数据源与下载逻辑
├── renderer.py             # 图片渲染模块
├── voice_page.py           # Pages 管理后端
├── prts.py                 # PRTS Wiki API 客户端
├── constants.py            # 全局常量（版本、限额、语言与资源映射）
├── config.py               # 配置对象、自动迁移和 AstrBot 配置保存
├── pages/voice-manager/    # 管理端前端（modern/ 新版，classic/ 经典版）
├── SourceHanSerifCN...otf  # 字体文件
├── _conf_schema.json       # WebUI 配置定义
├── requirements.txt        # 依赖列表
└── CHANGELOG.md            # 更新日志
```

### 2. 插件数据目录

位于 `AstrBot/data/plugin_data/astrbot_plugin_mrfz/`：

```text
astrbot_plugin_mrfz/
├── assets/                 # [自动生成] 干员头像缓存目录
│   ├── 阿米娅.png
│   └── ...
├── voices/                 # [自动生成] 语音文件存储目录
│   └── 阿米娅/
│       ├── cn/             # 中文语音
│       ├── jp/             # 日语语音
│       └── skin/           # 皮肤语音目录
├── custom_commands.json    # [自动生成] 自定义绑定数据
├── operator_aliases.json   # [自动生成] 自定义干员别称
├── voice_index.json        # [自动生成] 本地语音索引缓存
├── operator_catalog.json   # [自动生成] PRTS 干员列表缓存（12 小时刷新）
├── voice_texts/            # [自动生成] PRTS 台词缓存
├── voice_records/          # [自动生成] 完整语音资源记录缓存（1 小时刷新）
├── render_cache/           # [自动生成] 固定的 help.png 与 list.png
├── config_backups/         # [自动生成] 数字语言配置迁移前的备份
├── page_manager/           # [自动生成] 回收站、备份、导出和审计
└── quarantine/             # [自动生成] 隔离的损坏语音文件
```

语音预览与下载共用 PRTS 资源计划，头像地址随语音记录一起获取，有效本地头像会直接复用。旧编号修复覆盖完整编号表；语言目录修复只在内容摘要确认来源后移动文件，补下载任务写入 `voice_index.json`，失败时保留文件并在下次启动重试。

ZIP 导入会先完成校验和备份，再统一提交；写入失败会尝试回滚。若回滚失败，错误信息会给出保留的暂存目录，其中 `recovery.json` 记录目标、暂存文件和备份路径。此时不要手动删除该目录或对应备份，需按恢复清单核对后处理。

## ⚠️ 注意事项

1. **资源来源**：所有语音、图片和台词均通过 API 获取自 [PRTS Wiki](https://prts.wiki/)，请遵守相关使用协议。
2. **网络问题**：批量下载语音时请确保网络通畅，以免下载不完整。
3. **文件删除**：可自行在`\data\plugin_data\astrbot_plugin_mrfz\voices\`目录下删除不需要的语音文件，并在之后重载插件。
4. **版本更新与数据迁移**：3.8.2 保持语音索引 v4及持久化补下载和绑定修正记录，自动备份并迁移旧数字语言配置，同时刷新语音记录和台词缓存，重新核对旧语言目录来源。启动时会先迁移旧皮肤目录、补齐稳定索引，再在后台核对旧语言目录；旧编号按角色和语言在播放、绑定或下载时修复。核对会联网请求 PRTS，失败保留文件并在后续启动或操作时重试。请留意日志，避免迁移期间反复重载插件。
